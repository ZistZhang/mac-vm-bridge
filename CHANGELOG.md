# Changelog

## 0.1.0

- Cross-platform Flutter application for Windows, macOS, and Android.
- MinerU V4 precise parsing API integration.
- Automatic long-PDF splitting by page and actual byte limits.
- Recursive handling of image-heavy oversized chunks.
- Persistent resumable jobs, retries, cancellation, and multi-token failover.
- Safe result extraction, Markdown merge, asset path rewriting, manifests, and Agent-ready ZIP packages.
- Native file picker, desktop drag and drop, Android share target, secure token storage, responsive light/dark UI.
- GitHub Actions builds for installable EXE, unsigned DMG, and installable APK.
